# leetcode-python

这套路径紧扣每周的 Lecture 核心要点，并精选了 **4 道 LeetCode 线上原题**（2 Easy, 1-2 Medium, 0-1 Hard），帮助你通过高强度、结构化的刷题，在代码实现层面彻底吃透课程的数学模型与动态数据结构。

### **Week 5: 二叉搜索树与平衡二叉树 (BST & AVL Trees)**

*   **核心学习要点**：
    *   **BST 性质**：掌握左子树节点值 < 根节点值 < 右子树节点值的有序性质。
    *   **BST 操作**：掌握在二叉搜索树中进行检索、插入、以及**删除节点**（特别需要处理待删除节点有双子树时的前驱/后继替代逻辑）的步骤。
    *   **AVL 平衡旋转**：理解由于普通 BST 在极端输入下会退化成 \\(O(n)\\) 链表，因此需要通过 AVL 树的左旋、右旋（LL, RR, LR, RL）来维护平衡，使树高始终保持在 \\(O(\log n)\\)。

### **Week 9: 最短路径与最小生成树 (Shortest Path & MST)**

    *   **单源最短路径（Dijkstra）**：掌握 Dijkstra 算法对非负权有向图的处理。理解为何需要借助优先队列（最小堆）来完成每轮 \\(O(\log V)\\) 的松弛（Relaxation）操作。
